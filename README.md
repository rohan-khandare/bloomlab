# BloomLab

BloomLab is an interactive educational web application that explains and demonstrates how a Bloom Filter works.

Instead of only showing the theory, BloomLab lets you interact with a real Bloom Filter through a React interface and a Node.js backend.

You can:

- Insert values into a Bloom Filter
- Visualize the underlying bit array
- See which bit positions are generated by hash functions
- Check whether a value is probably present
- Reset the filter
- Observe a real false positive
- View live filter statistics
- See the mathematical estimation of false-positive probability

---

## Why BloomLab?

Bloom Filters are a probabilistic data structure used when fast membership checks and memory efficiency are important.

They are commonly used in systems such as:

- Databases
- Caches
- Distributed systems
- Web crawlers
- Networking systems
- Storage engines

The main idea is simple:

> A Bloom Filter can tell you that an item is definitely not present, or that it is probably present.

The second case is where false positives can occur.

---

## How a Bloom Filter Works

BloomLab uses:

- A bit array of `m` bits
- `k` hash functions
- Inserted items

For every inserted value:

1. The value is passed through multiple hash functions.
2. Each hash function produces a position in the bit array.
3. Those positions are set to `1`.
